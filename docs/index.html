Abstract

Vatra.ai is an open-source AI engineering ecosystem developed by Vantara Intech (Vantara Infrastruktur Teknologi) to make both software code intelligence and real-world Edge Vision accessible without heavy cloud lock-in. The ecosystem centers on two lightweight pillars: Vatra-Coder-1.5B, a compact 1.5-billion-parameter code generation model designed for low-resource local inference, and vatra-core, a modular Physical AI and spatial vision runtime.

  • Vatra-Coder-1.5B: Compact 1.5B parameter scale engineered to run efficiently on consumer GPUs, developer laptops, and edge devices.
  • Zero-dependency core (vatra-core v0.1.0): Built on pure Python 3.10+ standard library for instant setup and CI verification.
  • Hardware-accelerated Edge Vision: ONNX Runtime detector backend prioritizing NVIDIA TensorRT and CUDA execution providers with automatic CPU fallback.
  • Built-in spatial reasoning: Ray-casting SpatialZoneMonitor emits structured ZoneEvent alerts when watched classes enter polygonal regions of interest.
  • Open source and free to all: Released under the Apache-2.0 License for global developer, research, and commercial adoption.

Models & Ecosystem

Focusing on a 1.5B parameter footprint allows Vatra-Coder-1.5B to pair naturally with vatra-core in resource-constrained developer and edge workflows, lowering memory requirements compared to multi-billion-parameter cloud models while preserving fast local iteration.

Architecture

EdgeVisionPipeline connects four modular stages from camera or synthetic packet ingestion through spatial event callbacks. Each stage adapts cleanly to mobile, desktop, and edge server environments.

01. INGEST →

FrameSource

SyntheticSource, webcam, video file, or RTSP stream producing FramePackets.

02. DETECT →

DetectorBackend

MockDetector or OnnxRuntimeDetector (TensorRT / CUDA / CPU).

03. REASON →

SpatialZoneMonitor

2D ray-casting polygon ROI checks filtered by watched object labels.

04. OUTPUT •

ZoneEvent

Real-time on_event callbacks, CLI alerts, and PipelineStats telemetry.

Quickstart (bash / powershell) 
git clone https://github.com/rozzulabil-dev/vatra-core.git
cd vatra-core
pip install -e .

# Inspect runtime and ONNX / CUDA / TensorRT providers
vatra info

# Run zero-dependency synthetic pipeline benchmark
vatra benchmark --frames 30

# Optional: camera ingestion + NVIDIA CUDA / TensorRT runtime
pip install -e ".[vision,cuda,yaml]"
