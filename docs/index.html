Abstract

Vatra.ai (vatra-core) is an open-source Physical AI and Edge Vision software framework developed by Vantara Intech (Vantara Infrastruktur Teknologi). Deploying spatial perception in real physical environments—such as workplace safety perimeters, industrial visual inspection, and logistics monitoring—frequently suffers from heavy framework dependencies and brittle sensor glue code. To address this, vatra-core provides a clean, modular pipeline built on a zero-dependency Python standard library core with optional ONNX Runtime acceleration that prioritizes NVIDIA TensorRT and CUDA execution providers while falling back cleanly to CPU.

  • Zero-dependency core implemented with Python 3.10+ standard library for instant verification, CI benchmarks, and minimal runtime footprint.
  • Hardware-accelerated inference via OnnxRuntimeDetector, automatically selecting TensorrtExecutionProvider and CUDAExecutionProvider on NVIDIA GPUs and Jetson devices.
  • Built-in spatial reasoning using ray-casting SpatialZoneMonitor to emit structured ZoneEvent alerts when watched labels enter polygonal regions of interest.
  • Unified frame ingestion supporting SyntheticSource benchmarks alongside VideoStreamSource for webcams, local files, and RTSP camera feeds.
  • Open source and free to all under the Apache-2.0 License for research, developer tooling, and commercial deployment.

Architecture

EdgeVisionPipeline coordinates four decoupled stages: frame ingestion, object detection, polygonal spatial zone evaluation, and event/telemetry reporting. Every stage implements lightweight Python protocols (FrameSource and DetectorBackend), allowing developers to test logic without camera hardware and swap in accelerated ONNX/TensorRT models for deployment.

Runtime Backends & Verification

The vatra-core v0.1.0 release focuses on reliable pipeline orchestration and provider auto-detection. In our reference synthetic benchmark (vatra benchmark --frames 20 on Python 3.13, Windows CPU), pipeline orchestration and ray-casting spatial evaluation run at an average overhead of 0.0218 ms/frame across 20 frames (40 detections, 14 triggered zone events). Hardware model benchmarks on NVIDIA Jetson Orin and discrete CUDA GPUs are scheduled in the next roadmap phase.

Quickstart (bash / powershell) 
git clone https://github.com/rozzulabil-dev/vatra-core.git
cd vatra-core
pip install -e .

# Inspect detected runtime and ONNX / CUDA / TensorRT providers
vatra info

# Run zero-dependency synthetic pipeline benchmark
vatra benchmark --frames 30

# Optional: camera ingestion + NVIDIA CUDA / TensorRT runtime
pip install -e ".[vision,cuda,yaml]"
