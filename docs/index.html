Built for Edge Efficiency and Spatial Awareness

Designed by Vantara Intech to eliminate glue-code overhead when moving from prototype vision models to physical environments.

Zero Friction

Zero-Dependency Core

Core pipeline orchestration, ray-casting spatial polygon logic, and the vatra CLI run on pure Python standard library out of the box.

NVIDIA Ready

TensorRT & CUDA Priority

OnnxRuntimeDetector automatically prioritizes TensorrtExecutionProvider and CUDAExecutionProvider on NVIDIA GPUs and Jetson devices, with clean CPU fallback.

Physical AI

Spatial Zone Intelligence

Built-in SpatialZoneMonitor evaluates object centers against polygonal regions of interest and emits structured ZoneEvent payloads for watched labels.

Modular Ingestion

Unified Edge Ingestion

Swap seamlessly between SyntheticSource for CI benchmarks and VideoStreamSource for webcams, local files, or live RTSP industrial camera feeds.

Pipeline Architecture

Four composable stages from physical camera frames to real-time spatial decisions.

01 · Ingest

FrameSource

Synthetic, Webcam, Video File, or RTSP stream yielding FramePacket.

->
02 · Detect

DetectorBackend

MockDetector or OnnxRuntimeDetector (TensorRT / CUDA / CPU).

->
03 · Reason

SpatialZoneMonitor

Ray-casting polygon checks filtered by target physical classes.

->
04 · Act

ZoneEvent

Structured callbacks and throughput telemetry via PipelineStats.

Quickstart

Install the core package in seconds, or include optional vision and NVIDIA CUDA acceleration extras.

bash / powershell 
git clone https://github.com/rozzulabil-dev/vatra-core.git
cd vatra-core
pip install -e .

# Inspect runtime & ONNX / CUDA / TensorRT providers
vatra info

# Run zero-dependency synthetic pipeline benchmark
vatra benchmark --frames 30

# Optional: install camera ingestion + NVIDIA CUDA / TensorRT runtime
pip install -e ".[vision,cuda,yaml]"
